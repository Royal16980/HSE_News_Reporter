# Maintenance Guide

## Daily Tasks
- Review analytics report at 9 AM.
- Monitor pending review count and approve items.
- Scan error logs for critical issues.
- Verify workflows completed successfully.

## Weekly Tasks
- Review weekly newsletter content before send (Friday 10 AM).
- Audit RSS sources for availability.
- Inspect social media engagement and adjust tags.

## Monthly Tasks
- Rotate API keys if needed.
- Review automation quotas and adjust scheduling logic.
- Validate backup and restore procedures.
